**Deskripsi Singkat** 
Aplikasi yang saya buat ini adalah aplikasi android sederhana berbasis Jetpact Compose yang mempunyai fitur :
- Input nama pengguna 
- Menampilkan teks "Halo + hasil input"
- Fitur Toggle untuk mengubah tema menjadi mode gelap dan mode terang

**Cara Menjalankan**
Membuka Kode
1. Download repository ini
2. Buka folder menggunakan Android Studio
3. Aktifkan mode pengembang di HP android 
4. Sambungkan HP android atau gunakan emulator
5. Klik ikon segitiga hijau untuk me run dan aplikasi berhasil dijalankan

Instalasi Langsung
1. Unduh file .apk
2. kirim file ke perangkat andorid
3. buka file APK dan pilih install
4. setelah selesai menginstall klim buka dan aplikasi berhasil dijalankan
